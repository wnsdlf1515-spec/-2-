# 도트와 효과음

도시는 city-map.js의 정수 좌표 Canvas 래스터 코드로 직접 생성한다. 기본 캔버스480×320, 지면24×12 아이소메트릭 타일, 정수 배율1/2/3, imageSmoothing 비활성, CSS pixelated 표시를 사용한다. 건물 위치와 식별자를 유지하며 정책·공사·실제 이용 상태를 그린다. 시설 실루엣 클릭 영역과 그리기 순서를 맞추고 선택 금색/호버 파란색/공사 구조물을 구분한다.

사람·차량은 실제 개별 시민/교통 계산이 아닌 도시 상태에 따른 보조 표현이다. 3개 생활권은 공통 배치 템플릿을 사용하는 절차적 도트 자산이다. 첨부 콘셉트 이미지 수준의 건물 다양성과 밀도를 모두 구현한 것은 아니다. 전문 작가가 검수한 완성 자산 팩으로 표시하지 않는다.

settings.js의 Web Audio triangle oscillator 및 짧은 envelope로 선택·확정·완공·주의 음을 생성한다. 외부 음원/샘플/라이브러리 음원을 가져오지 않았고 배경음은 없다. 소스에 생성 방식이 포함된다. 사용자 입력 후 AudioContext를 활성화하며 음소거·탭 숨김 시 음을 중단한다. 음량 및 설정은 브라우저에 저장한다. 테스트는 실제 오디오 스케줄링을 확인했으며 스피커 청취 평가는 하지 않았다.
