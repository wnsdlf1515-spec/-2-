# 6단계 RC1 검증 기록 — 2026-10-19

## 진단과 수정

- 5단계 실제 3개 시나리오 플레이와 10개 엔진 테스트로 기존 사업/비용/운영/저장/종료 작동을 확인했다. 문서만 보고 완성으로 간주하지 않았다.
- 튜토리얼·설정 부재 → 실제 지역 선택/정책 검토/시행/결산/대상 확인을 따라가는 안내, 건너뛰기·다시 보기·학습 상태 보존을 추가했다.
- 모달 뒤 입력 가능 → 배경 inert, 이벤트 가드, 키보드 포커스 제한 및 복귀를 적용했다. 정책·턴·사건 중복 클릭을 검증했다.
- 지도 드래그/선택 혼동 → 6px 이동 임계값, 드래그 종료 선택 억제, 시설 실루엣 클릭 영역을 적용했다.
- 좁은 화면에서 지도 잘림 → 노트북 기본1×, 큰 화면2×, 정수 확대 및 드래그, 안내 영역 줄바꿈을 적용했다.
- 정지 중 반복 그리기 → 모달·움직임 줄이기·정지·hidden 시 RAF 중단, 복귀 시 한 루프만 예약한다.
- 저장 실패가 숨겨짐 → 실패 안내, JSON 내보내기, 손상된 자동 저장 원본 내보내기를 제공한다. 불러오기는 확인 후 교체하며 오래된 튜토리얼 대상도 초기화한다.
- 종료 뒤 후반 투자 안내가 남음 → 종료/지역 비교/재도전 안내로 교체했다.
- 인구 증가만의 성공 오해 → 생활 여건 목표, 고령화/이주민 표현, 교육용 모형의 가정과 단순화 안내를 유지·정리했다. 정책 수치는 실제 정책 예측이 아니다.

## 성능 측정 범위

Linux x64 Chromium154.0.8037.57 headless, AMD EPYC9V74(노출 논리 CPU5),1366×768,DPR1. 종료 도시 상태에서2205ms 동안17회 그리기, 평균4.75ms/최대8.20ms. 12회 UI 생활권 선택 평균17.46ms/최대34.40ms, 재구성 후1100ms 동안8회 그리기로 루프 중복 없음. 정지700ms 동안 그리기0회, RAF 예약 없음. 서버 가상환경의 작은 표본이며 일반 노트북 FPS 보증이 아니다.

CDP 페이지 freeze/resume 후 모델 유지 확인. headless 실제 탭 전환은 document.hidden을 true로 만들지 않아 실제 숨김 탭의 렌더 중단은 미검증으로 남긴다. 코드에 visibilitychange 처리와 정지 경로는 존재한다. 시뮬레이션은 버튼 입력으로만 진행한다.

## 남은 한계와 공개 판단

확인한 Chromium 경로에서 진행 차단 오류는 발견되지 않았다. 배포 후보 HTML은 정적 서버에 올릴 수 있게 준비했으나 외부 공개는 수행하지 않았다. Firefox/Safari, 실제 스피커 음색·음량, 실제 노트북 장시간 성능/배율125%·150%, file:// 저장은 검증하지 않았다. 공개 대상 브라우저/기기에서 직접 시연한 뒤 공개 여부를 결정한다.

절차적 도트의 생활권 배치 반복, 건물 종류 부족이 남는다. 별도 BGM은 없다. 균형은 3개 시나리오 및 기록한 전략/시드 표본에 한정하며 모든 정책 순서가 검증됐다고 주장하지 않는다. 시뮬레이션 규칙은 5단계와 동일하다.
