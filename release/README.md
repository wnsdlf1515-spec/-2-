# 다온시 리부트 v0.5 — 도시 운영

2년씩 3기간 동안 도시를 운영하고, 같은 조건으로 재도전하며 전략을 비교합니다. 시설·준비 상태·유지비·인력·서비스 수요가 기간을 넘어 이어집니다.

압축을 풀고 **index.html**을 Chrome/Edge로 여세요. 외부 이미지·폰트·API·학생 계정 없이 실행합니다. GitHub Pages 웹사이트 배포는 하지 않았습니다.

도시 지도와 보고서는 같은 규칙 엔진의 도시 상태를 표시합니다. 준비 중 시설은 공급에서 제외하며, 예산·인력이 부족하면 공급과 시설 표시가 함께 바뀝니다. 인구 증가만을 성공으로 삼지 않습니다.

클라우드 관리자 정책으로 file:// 직접 열기는 검증하지 못했습니다. 학교 PC의 파일 열기와 프로젝터 가독성을 확인해 주세요. 모든 수치는 수업용 가정이며 실제 수업의 난이도·흥미 검증은 남아 있습니다.
