# 다온시 리부트 v0.2 — 수업용 다운로드

고등학교 통합사회2 인구 문제 공개수업용 협력 정책 게임입니다.

## 다운로드

- [실행본·수업 자료 꾸러미 ZIP](https://github.com/wnsdlf1515-spec/-2-/raw/refs/heads/main/release/daon-reboot-v0.2.zip)
- [지도안·부서 활동지·규칙 PDF (A4 10쪽)](https://github.com/wnsdlf1515-spec/-2-/raw/refs/heads/main/release/daon-class-materials-v0.2.pdf)
- [게임 HTML 파일](https://github.com/wnsdlf1515-spec/-2-/blob/main/release/index.html) — 파일 화면의 **Download raw file** 버튼으로 저장합니다.

저장소가 비공개라면 접근 권한이 있는 GitHub 계정으로 로그인해야 합니다. 직접 다운로드 링크가 열리지 않으면 해당 파일의 GitHub 화면에서 **Download raw file** 버튼을 사용하세요.

## 시작 방법

1. ZIP을 내려받아 압축을 풉니다.
2. `index.html`을 Chrome 또는 Edge로 엽니다.
3. **1턴 연습**으로 선택과 결과 화면을 확인한 뒤 본 수업을 시작합니다.
4. PDF를 인쇄하고, 교사 PC와 대형 화면으로 다섯 모둠의 정책회의를 진행합니다.
5. 수업 종료 전 **저장·설정 → 수업 기록 내보내기**로 JSON 기록을 보관합니다.

게임 실행에는 학생 계정·AI 호출·외부 자산 다운로드가 필요 없습니다. 이 저장소 업로드는 파일 배포이며 GitHub Pages 웹사이트 배포는 아닙니다.

규칙 엔진 14개, 실제 Chromium 기능 검사 26개가 통과했습니다. 네트워크 차단 후 도전 전체도 확인했습니다. 클라우드 브라우저의 관리자 정책으로 로컬 파일 더블클릭 시작은 검사하지 못했으므로, 학교 PC에서 실행과 프로젝터 가독성을 확인해 주세요. 실제 50분 수업 리허설은 남아 있습니다.

모든 인구 자료·정책 효과 수치는 수업용 가정이며 실제 미래를 예측하지 않습니다. 승패로 학생을 평가하지 않습니다.
