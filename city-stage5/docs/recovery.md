# 복원 기록

- 원래 city-stage5/city-connected 폴더와 관련 ZIP은 현재 파일시스템·Git 기록에서 찾을 수 없었다.
- 사용자 요청에 따라 기존 v0.5는 보존하고 별도 city-stage5에서 대화의 8턴·3생활권·6정책 및 5단계 명세를 기준으로 재구현했다.
- 기존 미술 파일을 복원했다고 주장하지 않는다. src/city-map.js는 자체 제작 절차적 픽셀 자산이다.
- 복구 단위는 소스·테스트·README·실행 HTML을 포함한 release/daon-city-stage5-source.zip이다. 이 파일을 내려받아 보관하면 새 환경에서 풀고 이어갈 수 있다.
- HTML 한 파일도 CSS와 JS를 모두 포함하므로 최소 실행본으로 보관할 수 있다. 플레이 진행은 별도 JSON 내보내기로 보존한다.
- 로컬 Git 기록은 현재 체크아웃의 복구 수단이며 원격 서버나 다음 클라우드 환경에 보관됐다는 보장은 아니다. 원격 push 또는 공개 배포는 이 작업에 포함하지 않았다.
