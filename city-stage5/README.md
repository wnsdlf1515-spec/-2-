# 다온시 — 여덟 해의 선택 (5단계 복원판)

이전 작업 폴더가 제공되지 않아 대화에 남은 규칙·코드를 바탕으로 별도 구현한 버전입니다. 원래 파일의 바이트 단위 복구가 아니며, 픽셀 자산은 새로 제작했습니다. 저장소의 기존 `release/` v0.5는 수정하지 않았습니다.

## 실행과 복구

`release/daon-city-stage5.html`은 CSS·규칙·도트 렌더러를 포함한 단독 실행 HTML입니다. 외부 이미지, 글꼴, 계정, 인터넷 연결이 필요 없습니다. 브라우저에서 열거나 정적 웹 서버로 제공할 수 있습니다. 자동 저장은 같은 브라우저·주소에만 남으므로 **저장 → 파일 내보내기**로 JSON도 보관하세요. file:// 저장 동작은 브라우저에 따라 다릅니다. 이 작업의 실제 플레이 검증은 로컬 HTTP Chromium에서 수행했습니다.

```sh
cd city-stage5
node tools/build.cjs
node tests/engine.test.cjs
node tests/strategies.cjs
python3 -m http.server 4179 --bind 127.0.0.1
```
다른 터미널에서 `node tests/browser.cjs`, `node tests/ui-extra.cjs`를 실행하면 브라우저 검증을 재현합니다. Node 20 이상, Playwright 1.62.1, `/usr/bin/chromium`이 필요합니다. 새 개발 환경에서는 `npm install`로 테스트 의존성을 설치하세요. 빌드와 규칙 테스트에는 외부 패키지가 필요 없습니다. 현재 환경에 설치된 Playwright와 Chromium을 재사용했고 새 npm 설치는 하지 않았습니다.

공개 웹 배포는 하지 않았습니다. 로컬 서버 주소는 내부 검증용입니다.

## 한 판의 흐름

1. 시나리오·목표·시드를 고릅니다. 첫 플레이 추천은 **다시 머무는 도시**입니다.
2. 생활권을 바꾸며 공실·채용 여유·서비스 병목을 확인합니다. 시설 또는 지도 아래 버튼으로 장소를 선택할 수 있습니다.
3. 추천 사업 또는 **전체 6개**에서 정책을 고르고 비용·운영 시작 시점을 확인한 뒤 투자합니다.
4. 다음 해로 진행하면 지연 사건 효과 → 사업 완공 → 운영·재정 → 인구 → 성취·새 사건 순서로 결산합니다.
5. 2·4·6년차 결산에는 조건을 만족하는 기회가 최대 1개 제시됩니다. 비용 없는 협력안도 있고, 사건 창을 닫고 도시를 살펴본 뒤 결정할 수 있습니다. 다른 해에는 투자 성과를 지켜봅니다.
6. 8년차 종료 후 목표 조건, 초기 대비 변화, 주요 선택, 남은 문제와 다음 도전 제안을 봅니다. 도시를 계속 살펴볼 수 있습니다.
7. **같은 조건 재도전**은 목표·시나리오·시드를 유지합니다. **새로운 조건**은 다른 시나리오·시드로 시작하며 완료 기록을 최대 10개 보존합니다. 영구 능력치 상승은 없습니다.

## 초기 조건 3종

| 시나리오 | 문제의 원인 | 유리한 판단 |
|---|---|---|
| 다시 머무는 도시 | 세 생활권 모두 최초 빈 일자리 0개. 기존 주거지는 빈집 190호 | 일자리·직업 교육 후 정착 연결, 다른 지역 주택·일자리 순서 검토 |
| 맞이할 준비가 필요한 도시 | 중심·산업 지역 빈 주택 각 2호, 일자리 여유와 부족한 돌봄 | 주거 확보 뒤 유입에 따른 서비스 수요 확인 |
| 가까운 일상의 도시 | 중심·기존 주거지 고령 주민 증가, 운영 인력과 의료 접근 부족 | 돌봄 전환·의료 연결·시설 재편의 인력과 정원 비교 |

모두 초기 인구 10,000명·보유 90억이지만 연령 구성과 공급·접근 조건이 다릅니다. 초기 취업은 노동 공급·일자리 이하로 맞춥니다. 창문과 입주·취업·서비스 충족 막대는 해당 지표를 읽습니다. 같은 지도의 대표 구역 템플릿을 재사용하며 지역마다 독립된 고유 지형은 아직 없습니다.

## 정책과 지속성

| 정책 | 투자 / 준비 / 연간 비용 | 기능과 시각 변화 |
|---|---|---|
| 주택 정비 | 22억 / 2년 / +1억 | 주택 +100호. 공사 구조물→정비된 외관·보행 공간, 입주는 별도 |
| 일자리·직업 교육 | 18억 / 1년 / +2억 | 일자리 +180·인력 환산 +30명. 사업장 정비·간판·활동 |
| 돌봄센터 전환 | 24억 / 1년 / +3억 | 정원 +70·인력 환산 +35명. 공사→차양·지붕·출입구 |
| 의료·이동 연결 | 10억 / 즉시 / +2억 | 의료 +18%p·돌봄 접근 +14%p, 공유 한도 증가. 정류장 표시 |
| 정착·지역사회 연결 | 8억 / 즉시 / +1억 | 주택·일자리 조건 안에서 전입 연결 개선. 안내 거점 |
| 기존 시설 재편 | 16억 / 1년 / −2억 | 정원 −10·인력 환산 +35, 접근성 개선. 별관 정비·벤치·보행 공간 |

신규 정책은 연 1개, 건설은 동시 1개입니다. 지역 정책은 생활권별 한 번, 도시 정책은 도시 전체 한 번만 투자합니다. 주택·재편은 영구 전환이며 나머지는 운영 개시 후 중지·재개할 수 있습니다. 중지하면 정책 효과·유지비가 함께 없어지고 외관과 투자 이력은 남습니다. 환급은 없습니다. 같은 해 같은 사업의 운영 조정을 반복할 수 없습니다. 종료 전에 준비를 마칠 수 없는 신규 사업은 막습니다.

추천 목록은 현재 병목을 반영한 최대 3개입니다. 무작위 덱이나 잠긴 필수 카드가 없으며 기본 6개는 항상 열어볼 수 있습니다.

## 사건 6개

모든 선택은 투자비를 즉시 내고 **1년 뒤 한 번만** 효과가 발생합니다. 6년차 제안도 7년차에 반영돼 마지막 결산 전에 확인할 수 있습니다. 사건은 연간 신규 정책 기회를 사용하지 않지만 같은 보유 예산을 경쟁합니다. 추가 유지비는 기본 운영비에 포함한 단순화이며 무제한 확장이 아니라 사건 종류별 한 번만 발생합니다. 아래 수치는 교육용 가정입니다.

| 사건·발생 조건 | 대응 A | 대응 B |
|---|---|---|
| 기업 입주: 빈 주택 <35, 빈 일자리 ≥30 | 4억, 일자리 +50 | 0억 교육 협력, 돌봄 인력 환산 +12 |
| 빈집 공동 정비: 빈집 ≥45 | 6억, 주택 +35 (입주 보장 없음) | 0억 상담 연결, 돌봄 접근 +4%p |
| 돌봄 확대: 미충족 ≥15 | 5억, 인력 환산 +25 | 0억 방문 일정 조정, 접근 +8%p |
| 의료 공동 활용: 의료 접근 <75% | 5억, 의료 +12%p | 0억 일정 통합, 의료 +5%p·돌봄 접근 +3%p |
| 공공시설 재배치: 지역·외부 제공 후 여유 ≥8 | 0억 공동 이용, 돌봄 접근 +6%p·의료 +4%p | 2억 소규모 재편, 정원 −5·인력 환산 +10 |
| 직업학교 협력: 노동 공급−취업 ≥80 | 6억, 일자리 +65 | 0억 돌봄 과정, 인력 환산 +15 |

사전 징후는 지역의 공실·가동 정원·미충족·의료 접근·노동 공급에서 확인합니다. 조건에 맞는 사건·생활권 후보 중 시드 기반으로 하나를 선택하므로 정확히 어떤 제안이 올지는 확정하지 않습니다. 강제 손실이나 특정 집단의 존재를 불이익으로 취급하는 사건은 없습니다. 모든 제안은 무료 대안을 가지며 대응 전까지 다음 해 진행이 잠깐 멈춥니다.

미응답 제안은 대상 위치에 깃발, 선택 후 준비 중에는 측량 표식, 효과 반영 뒤에는 내용에 맞는 안내판·보행 공간·작은 거점으로 표시합니다. 공급·입주·활동은 실제 수치와 함께 바뀝니다. 사건 내역은 시설 상세와 선택 기록에서 확인합니다.

## 성취와 결말 조건

성취는 처음 충족한 연도를 기록하고 지도에서 해당 장소를 볼 수 있습니다. 이후 지표가 악화돼도 ‘그때 달성한 기록’은 남습니다.

- 돌봄 공백 완화: 초기 충족률이 85% 미만인 생활권이 85% 이상 달성.
- 다시 채워지는 주거지: 해당 생활권 실제 입주가 초기보다 20호 초과 증가.
- 기존 시설의 새 역할: 시설 재편 운영 + 해당 생활권 충족률 70% 이상.
- 지속 가능한 서비스 개선: 도시 충족률 초기 대비 15%p 이상 개선 + 확정 운영 수지 비적자.

공통 목표는 보유 예산 ≥3억, 확정 사업 포함 연간 수지 ≥0, 운영비 전액 지급, 서비스 충족 ≥40%입니다. 정착 목표는 누적 순이동 ≥80명·취업 초기 대비 ≥40명, 생활 회복 목표는 서비스 ≥85%·인구 가중 의료 접근 ≥78%입니다.

성공하면 ‘정착 기반을 되찾은 도시’ 또는 ‘돌봄과 일상을 지킨 도시’. 목표 미달이어도 서비스 15%p 개선과 비적자 운영이면 ‘작아져도 서로를 돌보는 도시’, 취업이 늘면 ‘일자리 기반을 다진 도시’, 그 외에는 ‘다음 선택을 남긴 도시’입니다. 결말의 긍정적 표현과 목표 달성 여부는 구분해서 표시합니다.

## 모형과 저장

1턴=1년. 출생·사망·외부 전입·전출을 합산하며 내부 이동은 0으로 명시합니다. 20개 아동 코호트를 매년 이동하므로 이번 판에 태어난 아이가 노동인구로 들어가지 않습니다. 주택 공급/입주, 일자리/취업, 설계 정원/인력·예산 반영 정원/실제 이용, 현금/연간 수지를 구분합니다.

돌봄 수요는 아동·고령 인구로 계산합니다. 가동 정원은 시설·인력·취업 가능한 종사자·예산 중 제약을 적용합니다. 중심↔기존 주거↔산업 연결에서 남은 정원만 공유하고 외부 이용을 공급에 중복 산입하지 않습니다. 실제 개별 통행·개별 시설 이용자 배분은 계산하지 않습니다. 세입은 시나리오 초기 고용을 기준으로 변화시키며 실제 지방재정 예측이 아닙니다.

시드는 uint32, LCG 상태를 저장하며 선택 기록으로 초기 상태부터 검증 재생합니다. 같은 초기 조건·시드·선택은 같은 결과이고, 같은 시드에서도 정책이 조건을 바꾸면 사건이 달라집니다. 불러온 숫자를 그대로 신뢰하지 않고 다시 계산합니다. 이 복원판 저장은 `version:5, revision:restored-1`입니다. 이전 버전은 설명과 함께 거부하고 원본 키를 삭제하지 않습니다.

## 검증 및 한계

[검증 결과](docs/validation.md)와 `artifacts/`에 실제 브라우저 화면·결과 JSON을 보관합니다. 기본 규칙과 재현성 검증이 플레이 균형 전체를 입증하지는 않습니다. 무료 사건 대안 중심 전략을 비교했으며 모든 유료 대응·투자 순서·시드의 최적 조합은 탐색하지 않았습니다.

아트는 코드로 만든 원본 480×320 픽셀 자산, 24×12 아이소메트릭 타일, 1·2·3 정수 확대입니다. 첨부 콘셉트보다 소규모·단순한 표현이며 이전 도트 자산과 동일하지 않습니다. 시민·차량은 정해진 보조 경로를 사용하고 개별 주민이나 교통을 계산하지 않습니다. 시설별 수치는 생활권 합계라고 명시합니다.

다음 개선은 새 카드 확대보다 튜토리얼, 목표·병목 읽기, 키보드 모달 탐색, 사운드, 낮은 성능 기기·다른 브라우저 검증, 실제 사용자 플레이테스트와 배포 준비입니다.
