# 다온시 공개수업 발표 자료

문제 제시 → 인구 문제의 핵심 개념 → 조별 게임 안내 → 결과 비교 → 근거 있는 설명으로 연결하는 17장 자료입니다.

## 파일
- `daon-lesson.pptx`: 편집 가능한 본문·도형·차트, 슬라이드별 발표자 노트
- `daon-lesson.pdf`: 글꼴과 배치가 고정된 화면용 자료
- `발표자_진행노트.txt`: 교사용 질문과 진행 안내

## 수업 전 준비
1. 12장의 학생 접속 주소와 수업방 코드를 실제 값으로 바꿉니다. 교사용 비밀번호는 넣지 않습니다.
2. 50분 수업에서는 도입·개념·조작 안내를 약 12분 안에 진행합니다. 6·8장은 선택 설명, 16·17장은 참고용입니다. 17장을 모두 순서대로 강의할 필요는 없습니다.
3. 13장은 중간 점검, 14·15장은 플레이 후 비교와 정리에 사용합니다. 14장의 검증 예시 차트는 가능하면 당일 교사 화면의 실제 조별 집계로 대체합니다.
4. 20명 기준 2인 1기기로 운영하고 4턴에 조작자와 기록자 역할을 바꿉니다.

## 자료와 해석
- 첨부 사진의 인구 문제·해결 방안 내용을 요약했습니다. 첨부 교과서 PDF는 도구의 전송 용량 제한으로 원문을 확인하지 못했습니다. 교과서 쪽수·직접 인용·성취기준 코드를 임의로 넣지 않았습니다.
- 2장의 두 도시는 토의용 가상 사례입니다. 14장은 게임 검증 데이터이며 실제 학생 결과나 현실 통계가 아닙니다.
- 정책 비용과 효과는 수업용 모형입니다. 인구 증가량이나 게임 승패만으로 학생을 평가하지 않습니다.
- 게임 화면과 정책 표는 제작 시점 구현을 기준으로 합니다. 게임 업데이트 후에는 다시 확인하세요.

## 표시와 검증 범위
Noto Sans CJK KR 글꼴을 사용했습니다. 다른 PC에서 글꼴이 대체되면 배치를 확인하거나 PDF를 사용하세요. LibreOffice에서 17장 PDF 변환을 확인하고 표지·비교 사례·게임 화면·중간 질문·차트·정책 표·출처를 실제 렌더링으로 점검했습니다. Windows PowerPoint 및 교실 프로젝터에서는 직접 확인하지 않았습니다.
