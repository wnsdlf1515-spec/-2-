# 다온시 공개수업 자료 — 사진 기반 검토본

작성일: 2026-10-20. 통합사회2 인구 문제와 해결 방안, 다온시6단계 게임과 실시간 조별 수업 모드에 맞춘 자료입니다.

## 구성과 사용

- 학생용 PDF6쪽: 1~2쪽 사전 개념,3쪽 접속·조작 안내,4쪽 정책/규칙 참고표,5~6쪽 선택·비교 활동지.
- 교사용 PDF3쪽: 50분/20명/2인1조 운영안, 차트 해석과 발문, 평가 기준·출처와 반영 범위.
- 각 문서의 DOCX: Word 편집용. 편집 프로그램과 폰트에 따라 쪽 나눔이 PDF와 달라질 수 있습니다.
- HTML 및 게임 화면 이미지: 브라우저 열람·편집용. 같은 폴더의 이미지 파일을 함께 유지하세요.

학생에게 모든 자료를 수업 중 처음부터 읽히기보다는 개념1~2쪽을 사전에 안내하고,3~4쪽은 참고용,5~6쪽은 활동 중 사용하세요. 첫 게임20~30분은 예상이며 학생 대상 실측값이 아닙니다. 교과서 원문 대조와 학생 기기 리허설 후 사용을 권합니다.

## 출처·확인 범위

사용자가 제공한 사진의 인구 과잉·저출생·고령화·우리나라 지역 격차 및 해결 방안 내용을 요약·재구성했습니다. 원본 사진과 첨부 교과서 PDF 파일은 배포물에 포함하지 않았습니다. 게임 이미지는 개발 과정에서 실제 실행한 검증 화면입니다.

첨부된 「미래엔_통합사회2_교사용교과서_5단원.pdf」는 도구의32MB 전송 한도를 초과해 원문을 열지 못했습니다. 따라서 교과서의 특정 쪽·표현·도표와 대조를 완료한 자료가 아닙니다. 관련 부분만32MB 미만 PDF 또는 쪽 사진으로 제공하면 대조 후 개정할 수 있습니다.

사진의2018년 고령 사회 진입은 과거 서술임을 명시했습니다. 현재 인구 비율을 임의로 추가하지 않았고, 특정 성별·고령 주민·이주민을 문제의 원인으로 단정하지 않도록 문구를 정리했습니다. 게임의 수치는 실제 정책 예측값이 아닙니다.

## 검증

Chromium154 PDF 인쇄, A4학생6쪽/교사3쪽 확인. 모든 HTML 인쇄 페이지의 본문이 바닥글 위에 있고 가로 넘침이 없음을 자동 검사했습니다. 대표 정책표와 활동지의 실제 화면을 확인했습니다. PDF 한글 텍스트 추출 및 DOCX/ZIP 무결성 확인. Word/HWP 실제 편집 화면과 학교 프린터 출력은 미검증입니다.

## 재생성

`game-reference.json`은 city-stage6/src/engine.js의 정책/시나리오 데이터에서 생성했습니다. 게임 규칙 변경 시 이 파일을 갱신해야 합니다. Python python-docx/beautifulsoup4로 build_materials.py를 실행합니다. 저장소 루트 HTTP4196 서버를 켠 뒤 Playwright/Chromium으로 render.cjs를 실행하면 PDF와 레이아웃 검사 기록이 생성됩니다.
