## 구현 중 발견·수정

- 원본 엔진은 초기 턴을 history에 넣지 않음 → 집계에 별도의0턴 기준점을 추가.
- 서버 확인 응답마다 게임 화면을 다시 만들면 결산 창이 닫힘 → 상태가 같으면 화면을 유지.
- 개인 저장 슬롯과 교실 저장의 혼동 → 교실은 서버 상태를 로드하고 개인 신규/재도전/가져오기 버튼 제외, 저장 안내 구분.
- 다른 조의 선택마다 모든 조의 동일 상태를 재전송 → 개인 스트림은 수업 상태/자기 revision이 바뀔 때만 전송.
- 연결 끊김 중 낙관적으로 바뀐 도시 → 승인된 서버 상태로 복원하고 재연결 전 추가 선택 차단.

공개 URL 배포 및 학교 기기 실측은 이 기록의 통과 범위에 포함하지 않는다. Docker 결과는 배포 검증 기록에 별도로 기재한다.

## 패키징

Node24-alpine Docker 이미지 빌드 성공. 사용자 요청에 따라 실제 운영은 교사 PC 내부망 방식을 우선한다. 외부 호스팅 배포/유료 서비스 생성은 하지 않았다. Windows CMD는 배포 파일로 제공하되 실제 Windows 실행은 미검증이다.

배포 ZIP을 임시 폴더에 실제 압축 해제한 뒤 start-local.cjs를 실행해 암호 입력, 교사 방 생성, 게임 제공, SQLite 저장, 정상 종료를 확인했다. 암호가 출력에 포함되지 않는 것도 확인했다. artifacts/launcher-report.json 참조.
